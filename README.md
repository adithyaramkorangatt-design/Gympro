🏋️ GymPro – Workout Logger Web App

Track Your Fitness. Build Your Strength. Stay Consistent.

GymPro is a browser-based fitness and workout tracking application built using HTML, CSS, and JavaScript. It helps users manage their daily workouts, track water intake, monitor nutrition, calculate fitness metrics, and maintain gym consistency through a simple and responsive dashboard.

✨ Features

- 🔐 User Login: Create an account and log in with username and password.
- 📊 Fitness Dashboard: Personalized greeting, live clock, and date display.
- 💧 Water Intake Tracker: Track daily water consumption with a 3000 ml goal.
- 🏋️ Workout Logger: Record exercises, dates, sets, reps, and weights.
- 📈 Workout Statistics: Monitor total workouts, total weight lifted, and gym streaks.
- 🔥 Gym Check-in: Track daily gym attendance and consecutive workout days.
- ⏱️ Rest Timer: Built-in timer with multiple presets and completion beep.
- 🥗 Macro Tracker: Monitor daily protein, carbohydrates, fats, and estimated calories.
- ⚖️ BMI Calculator: Calculate BMI and view fitness categories.
- 💪 One Rep Max Calculator: Estimate maximum lifting capacity using the Epley formula.
- 💬 Motivational Quotes: Get random fitness motivation.
- 🌙 Dark & Light Mode: Switch between themes.
- 💾 Local Storage: Save user data directly in the browser.
- 📱 Responsive Design: Works on desktop, tablet, and mobile devices.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Application functionality and interactions
- LocalStorage – Browser-based data storage
- Web Audio API – Rest timer completion sound

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
4. Create an account and start tracking your fitness activities.

💾 Data Storage

GymPro uses browser LocalStorage to save user accounts, workout records, water intake, nutrition data, gym check-ins, and theme preferences.

No external database or backend is required.

⚠️ Limitations

- Passwords are stored in plain text in LocalStorage for demonstration purposes only.
- Data is limited to the browser and device where it was saved.
- Workouts currently support adding and deleting entries, but not editing.
- The application is designed for learning and demonstration, not production use.
